# Sales Performance Dashboard

## Project Overview
This project analyzes sales performance using Power BI.

## Tools Used
- Power BI
- Microsoft Excel

## KPIs
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Total Quantity Sold

## Dashboard Features
- Sales by Category
- Sales by Product
- Sales by City
- Monthly Sales Trend
- Interactive Slicers

## Business Insights
- Electronics generated the highest sales.
- Laptop was the top-selling product.
- Bengaluru generated the highest revenue.
- Monthly sales trends helped identify peak sales periods.
