# Task 2 - Exploratory Data Analysis & Business Intelligence

## Objective
Perform Exploratory Data Analysis (EDA), answer business questions using SQL, and create visualizations to identify business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- SQL
- GitHub

## Files Included
- EDA_Business_Intelligence.ipynb
- SQL_Queries.sql
- Sales_Dataset.xlsx
- Screenshots

## Business Questions
1. Top 5 selling products
2. Category-wise sales
3. Monthly sales trend
4. Gender-wise sales distribution
5. Descriptive statistics of Total Sales

## Key Insights
- Electronics generated the highest sales.
- Monthly sales showed noticeable fluctuations.
- Sales varied across product categories.
- Customer distribution differed by gender.
