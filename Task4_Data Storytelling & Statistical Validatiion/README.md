# Task 4 – Data Storytelling & Statistical Validation

## Objective
Analyze sales data using Power BI and present business insights through storytelling and statistical validation.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- PowerPoint
- GitHub

## Project Files
- Power BI Dashboard
- Presentation Slides
- Dataset
- Hypothesis Testing Summary

## Key Insights
- Electronics is the highest-selling category.
- Laptop is the top-selling product.
- Patna recorded the highest sales.
- March is the peak sales month.

## Business Recommendations
- Increase inventory for high-demand products.
- Improve marketing for low-performing categories.
- Use sales trends for inventory planning.
